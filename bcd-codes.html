BCD 8-4-2-1 Encoding

How It Works

Each decimal digit (0–9) is encoded independently as a 4-bit binary number.
The weights are:
8   4   2   1
Each bit position contributes its weight when the bit is 1:
Decimal value = 8·b₃ + 4·b₂ + 2·b₁ + 1·b₀
Important: BCD only uses codes 0000–1001 (0–9). Codes 1010–1111 (10–15) are invalid in BCD.
BCD ≠ Binary. For example:
Decimal 13:
Binary: 1101  (one 4-bit group)
BCD:    0001 0011  (two 4-bit groups: 1, 3)

BCD vs Pure Binary Comparison

BCD uses more bits but preserves decimal digit boundaries
BCD (Binary-Coded Decimal): Each decimal digit is encoded separately as 4 bits. The 8-4-2-1 code is the most common BCD code, using natural binary weights.
Why BCD? Used in digital displays (7-segment), financial calculations (exact decimal), clocks, meters, and anywhere decimal representation must be preserved.
Invalid codes: 4-bit patterns 1010 through 1111 (10–15) are unused in BCD — they don't correspond to any decimal digit.
